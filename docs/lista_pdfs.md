# Lista de PDFs da Fuvest para baixar

Links levantados das páginas de acervo da Fuvest (fuvest.br/acervo-vestibular-AAAA) em 19/10/2026.
O script `scripts/baixar_pdfs.py` baixa todos eles para `data/raw/`. Se algum link falhar, abra a página de acervo do ano e baixe à mão.

## Prioridade (baixe primeiro)

Para a 1ª entrega bastam os **matriculados finais por carreira** e os **inscritos**, de 2013 a 2022. Isso dá 20 PDFs e já cobre o antes e o depois das cotas (2018–2021). Os demais servem para o funil completo e para a 2ª entrega.

Observação: a Fuvest **não publicou o QASE em PDF a partir de 2023**. O item aparece na página, mas sem link. A série socioeconômica vai até 2022.
